# AI-SCOUT

Claude Code 생태계(CLI 판 · 공식 플러그인 · 스킬 · MCP · 커뮤니티 도구 · 새 개념)를 매주 훑어 **「이런 것도 있어요」 소식지**를 내고, 원하는 사람에게는 **자기 환경에 맞는 것만 골라 추천**한다. 도입은 언제나 사람이 한다.

## 두 층

```
           매주 월 09:00 KST — 엔진 저장소(여기)
┌──────────────────────────────────────────────┐
│ 공통 소식지  DIGEST.md                         │
│  수집 · 웹 검색 · 원본 읽기 → 후보마다 중립 사실   │
│  (무엇 · OS 지원 · 도입 비용 · 근거 · ⚠️ 보안)     │
│  → digest/<그 주 월요일>.md · .json · 공개 이슈   │
└──────────────────────┬───────────────────────┘
                       │ 소식지 JSON (raw)
          ┌────────────┴─────────────┐
          ▼                          ▼
   ① Watch 만 한 사람          ② 개인 스카우트  SCOUT.md
   소식지 이슈 알림을 받는다     프로필로 관련성 · 내 환경을 더해 고른다
                              → 내 결과 저장소에 추천 이슈 · 판정 · 장부
```

## 쓰는 법

1. **소식지만 받기 — 설치 없음**: 이 저장소를 **Watch → Custom → Issues** 로 두면 매주 `[AI-SCOUT 소식] YYYY-MM-DD` 이슈 알림이 온다. `digest/` 의 md 를 읽어도 된다.
2. **개인 추천 — 플러그인**(준비 중, 2단계): `/plugin marketplace add` → `/plugin install` → `/ai-scout:setup` 이 프로필 · 결과 저장소 · 주간 루틴을 만든다. 루틴은 그 주 소식지를 읽고 「내 환경에 맞는 것」만 이슈로 올린다 — 댓글 `1 채택` / `2 기각: 이유` 로 판정한다.
3. 팀 모드 — 나중.

## 무엇이 어디에

| | |
|---|---|
| `DIGEST.md` · `SCOUT.md` | 매주 절차 — 공통 소식지 · 개인 추천 |
| `sources.json` | 원천과 읽는 길 |
| `lib/` · `tools/` | 수집 · README 읽기 · 소식지 검사와 md · 하네스 연결 후보 · 선택 · 보고서 · 판정 줄 — Node 20+, 의존성 0, `node --test` |
| `digest/` | 공통 소식지와 그 장부 |
| `docs/design.md` | 설계 |

첫 사용자의 개인 결과(`profile.md` · `ledger.md` · `reports/`)도 이 저장소에 공개로 함께 있다 — 개인 환경 이름만 적고 사내 정보는 적지 않는다.
